# Workshop 14 – Git i Praktiken (Git-verkstad)

## Introduktion och Upplägg

Denna workshop täcker praktiskt arbete med Git, Feature Branches, Pull Requests och konflikthantering i grupp.

Allt övningsmaterial, källkod och instruktioner ligger i de tillhörande GitHub-repositorierna. Ni utgår direkt från instruktionerna i respektive repository.

---

## Pass 3: Avancerade Arbetsflöden och Kodstruktur

I det första passet tränar ni på att klona ett gemensamt projekt, skapa isolerade Feature Branches och genomföra samarbete via Pull Requests.

* **Övningsmaterial Pass 3:** [https://github.com/Java-Fullstack-FJAX26/git-verkstad-pass-3](https://github.com/Java-Fullstack-FJAX26/git-verkstad-pass-3)

### Hur ni startar Pass 3:
1. Navigera till länken ovan.
2. Läs igenom `README.md` i repositoryt för detaljerade instruktioner.
3. Klona repositoryt till din lokala miljö och följ guiden i övningen.

---

## Pass 4: Refaktorering, Pull Requests och Code Reviews

I det fjärde passet ligger fokuset på att genomföra refaktorering i en befintlig kodbas samt granska ändringar i teamet via Pull Requests och Code Reviews. (Observera att detta pass färdigställs och uppdateras direkt i repositoryt).

* **Övningsmaterial Pass 4:** [https://github.com/Java-Fullstack-FJAX26/git-verkstad-pass-4](https://github.com/Java-Fullstack-FJAX26/git-verkstad-pass-4)

### Hur ni startar Pass 4:
1. Navigera till länken ovan när ni är klara med Pass 3.
2. Läs igenom `README.md` i repositoryt för instruktioner kring uppgiften och konflikthanteringen.
3. Följ instruktionerna i repositoryt.
